# Repositório de práticas de Programação e Administração de Banco de Dados

Este repositório será o meu espaço para registrar exercícios, scripts, anotações e práticas relacionadas à disciplina de Programação e Administração de Banco de Dados.

## Objetivo

- organizar os exercícios e atividades da disciplina;
- praticar comandos SQL e administração de banco de dados;
- registrar configurações, testes e aprendizados;
- manter um histórico das atividades desenvolvidas ao longo do curso.
